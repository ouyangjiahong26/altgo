# altgo 文档

altgo 是桌面语音转文字工具。按住触发键（默认右 Alt）说话，松开后自动完成录音、转写与可选润色，结果写入系统剪贴板，并在屏幕底部悬浮窗中单行展示。

转写引擎二选一。本地引擎内嵌 sherpa-onnx，可选 SenseVoice 或 FireRedASR2 CTC，离线可用。在线引擎接入云端 ASR，默认 MiMo，无需下载模型，需要 API Key。润色为可选项，支持 OpenAI 兼容 API、Anthropic Messages API 与本机模型。

altgo 覆盖 Linux 与 Windows 的 x86_64 与 arm64 四个组合。Linux 支持 Ubuntu 22.04+ 的 x86_64 与 aarch64，Windows 支持 10+ 的 x86_64 与 arm64。macOS 暂不支持。

## 核心特性

| 特性 | 说明 |
|------|------|
| 长按即录 | 按住右 Alt 说话，松开自动转写 |
| 连续模式 | 双击进入连续录音，适合长篇发言 |
| 本地转写 | SenseVoice 或 FireRedASR2 CTC，离线可用，无需 API Key |
| 在线转写 | MiMo 等云端 ASR，无需下载模型，需要 API Key |
| LLM 润色 | 四档强度，支持多种 Provider，也可完全离线用本机模型 |
| 剪贴板与悬浮窗 | 自动写入剪贴板，悬浮窗可二次复制 |
| 本地历史 | 查看、复制、删除与重新润色，只保存文本 |
| 平台支持 | Linux（X11 / Wayland，x86_64 / aarch64），Windows 10+（x86_64 / arm64） |
