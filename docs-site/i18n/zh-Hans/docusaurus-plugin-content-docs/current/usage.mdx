# 使用说明

## 录音模式

### 长按模式（默认）

按住右 Alt（或你在设置里捕获的键）说话，松开即停止录音并进入转写与可选润色。

```text
按下右 Alt，开始录音
松开右 Alt，依次转写、润色（可选）、写入剪贴板、显示悬浮窗
```

### 连续模式

适合较长发言。双击触发键进入连续录音，再单击一次停止。连续模式下不必一直按住键，可以停顿思考。

```text
双击右 Alt，开始连续录音
单击右 Alt，停止并依次转写、润色（可选）、写入剪贴板、显示悬浮窗
```

## 处理流程

录音结束后，应用依次完成三步：

1. 转写。使用设置页选择的引擎。本地 SenseVoice 或 FireRedASR2 CTC 离线运行，在线转写需要网络与 API Key。
2. 润色。级别不是 `none` 时，文本交给所选润色引擎。远端引擎调用你配置的 API，本地引擎在本机运行。
3. 输出。结果写入系统剪贴板并在悬浮窗展示，同时追加到主页历史。只保存文本，不保存音频。

若剪贴板工具不可用，仍可在悬浮窗内点击复制。主页历史列表保留全文，可查看、复制或重新润色。

## 润色级别

| 级别 | 适用场景 |
|------|---------|
| `none` | 需要原话、低延迟 |
| `light` | 标点与错别字 |
| `medium` | 日常写作、语序通顺 |
| `heavy` | 正式文档、结构化重写 |

档位对远端引擎生效。本地引擎只有一档，`none` 关闭，其余档位等价于开启。

## 输出与界面

- 剪贴板：成功后默认写入，可在任意支持粘贴的应用中使用快捷键粘贴（`Ctrl+V`）。
- 悬浮窗：单行展示当前结果，悬停胶囊淡入关闭按钮。结果已自动写入剪贴板，全文在主页历史列表。
- 主窗口：主页包含状态、最近转写与历史列表（查看、删除、单条重新润色），另有设置页。首次安装会先走一遍分步引导（依次为触发键、转写引擎、润色）。空态里的“检测触发键”可以当场验证按下的键能不能被识别，装上后第一次进主页会展开这步提示，跳过也不影响使用。
- 系统托盘：显示或隐藏主窗口、退出应用。

历史数据默认位于 `~/.config/altgo/history.json`。

## 命令行

安装后可在终端启动：

```bash
altgo
```

应用不解析命令行参数。配置文件固定为 `~/.config/altgo/altgo.toml`，字段说明见[配置指南](./configuration)。

开发环境、构建与测试见 [`CONTRIBUTING.md`](https://github.com/ouyangjiahong26/altgo/blob/master/CONTRIBUTING.md)。
