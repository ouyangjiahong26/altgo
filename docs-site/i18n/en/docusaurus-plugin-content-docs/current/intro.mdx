# altgo Documentation

Welcome to **altgo**: a voice-to-text desktop app built on **Tauri + React + Rust**, supporting **Linux** (Ubuntu 22.04+, x86_64 and aarch64) and **Windows 10+** (x86_64 and arm64).

Hold the trigger key (**right Alt** by default) to speak; on release, transcription runs locally with **SenseVoice** (embedded sherpa-onnx), optionally followed by LLM polishing via an **OpenAI-compatible API**. After successful transcription the result is **copied to the system clipboard** when possible, and shown in an **overlay window** for easy verification or manual copying if clipboard access fails.

## Key Features at a Glance

| Feature | Description |
|------|------|
| **Hold to record** | Hold right Alt to speak; release to transcribe automatically |
| **Continuous mode** | Double-click to enter continuous recording, ideal for long speeches |
| **Local ASR** | Offline SenseVoice transcription, no API key required |
| **LLM polishing** | Four strength levels, multiple providers supported |
| **Clipboard + overlay** | Auto-copies to the clipboard; the overlay window allows re-copying |
| **Platform support** | Linux (X11 / Wayland, x86_64 / aarch64); Windows 10+ (x86_64 / arm64) |
