# Usage Guide

## Recording Modes

### Hold Mode (default)

Hold **right Alt** (or the key you captured in Settings) to speak; on release recording stops and transcription (with optional polishing) begins.

```
Press right Alt ──→ recording starts
   │
   │  speaking…
   │
Release right Alt ──→ stop → transcribe → (polish) → clipboard + overlay
```

### Continuous Mode

Suited to longer speech: **double-click** the trigger key to enter continuous recording, then **single-click** once to stop.

```
Double-click right Alt ──→ continuous recording
   │
   │  recording continuously…
   │
Single-click right Alt ──→ stop → transcribe → (polish) → clipboard + overlay
```

:::tip Tip
In continuous mode you do not have to keep holding the key — pause to think as you like; a single click stops it.
:::

## Processing Pipeline

After recording ends, the background runs these steps in order:

1. **Transcribe** — local SenseVoice
2. **Polish** (unless the level is `none`) — optimize the text via LLM
3. **Output** — **write to the system clipboard** and pop up the **overlay window**

If no clipboard tool is available, you can still click Copy inside the **overlay window**; the **history list on the home page** also keeps text records (text only, no audio stored).

## Polishing Levels

| Level | Best for |
|------|---------|
| `none` | Verbatim words and low latency |
| `light` | Punctuation and typos |
| `medium` | Everyday writing, smoother word order |
| `heavy` | Formal documents, structured rewriting |

## Output and Interface

- **Clipboard**: written by default on success; paste with the usual shortcut (`Ctrl+V`) in any app that supports pasting.
- **Overlay window**: shows the current result; you can copy again or close it.
- **Main window**: home (status, latest transcription, and the history list: view/delete/re-polish a single entry) and **Settings**; a step-by-step wizard (trigger key → engine → polishing) runs on first launch.
- **System tray**: show/hide the main window, quit.

History data lives at `~/.config/altgo/history.json` by default.

## Developers: Run the GUI Locally

```bash
cd frontend && npm install && cd ..
cargo tauri dev
```

Full release pipeline:
- Governed by **`make build`** at the repository root, consistent with CI.

## Command Line (if the `altgo` executable is installed)

```bash
altgo                              # start with default config
altgo --config /path/to/altgo.toml # use a specific config file
altgo --version
altgo --help
```
