# Configuration Guide

altgo uses a TOML configuration file. Every field has a default value, so you only need to change the parts you care about.

## Config File Location

`~/.config/altgo/altgo.toml`

## Transcription Engine Configuration

### Local SenseVoice (the only transcription method, no API key required)

```toml
[transcriber]
model = "sense-voice"   # filled in automatically after downloading on the Settings page; a model directory path also works
language = "zh"          # empty string = auto-detect (Chinese/English/Japanese/Korean/Cantonese)
threads = 0              # 0 = use all CPU cores automatically
```


## Polisher Configuration

altgo supports polishing transcribed text through an LLM.

### Polishing Levels

| Level | Effect | Needs API key |
|------|------|:---:|
| `none` | No polishing; the raw transcription is output as-is | No |
| `light` | Fix punctuation and typos | Yes |
| `medium` | Fix grammar and improve fluency | Yes |
| `heavy` | Structured rewriting, suited to formal documents | Yes |

### Example Configuration

```toml
[polisher]
level = "medium"
protocol = "openai"
api_key = "sk-your-key"
api_base_url = "https://..."
model = "your-model"
```

### The `api_base_url` Format

Both forms are supported; the app automatically assembles the correct request URL:

- **Without a version path** (origin): e.g. `https://api.deepseek.com`, `https://api.anthropic.com`; `/v1/chat/completions` or `/v1/messages` is appended automatically;
- **With a version path**: e.g. `https://api.moonshot.cn/v1`, `https://open.bigmodel.cn/api/paas/v4`, `https://dashscope.aliyuncs.com/compatible-mode/v1`; only `/chat/completions` or `/messages` is appended.

You may also paste a full endpoint (one ending in `/chat/completions` or `/messages`); it is then used verbatim.

The "Polishing" section of the Settings page has a **Test Connection** button: pick a provider preset, fill in the key, and click it — a minimal request is sent immediately with a readable result (invalid key, wrong URL, timeout, etc.), without saving first or doing an actual recording.

The provider list comes entirely from the Oh My Pi catalog (catalog.stencil.so, the same source the `omp models` command uses) and loads automatically when the Settings page opens—fetched once per session, with a retry on failure. Picking a provider fills in the address and protocol automatically; you only add the key. When offline or if the catalog is unreachable, fill in the API address and model manually.

### Thinking Level (Off by Default)

Voice polishing is a lightweight text task; reasoning models that "think" before answering would add seconds of latency and token cost for nothing. By default (`thinking_level = "off"`) the app automatically attaches the disable parameter for providers that support it — no configuration needed:

| Provider | Parameter attached automatically |
|---|---|
| Tongyi (dashscope), SiliconFlow (.cn / .com) | `enable_thinking: false` |
| Zhipu (bigmodel.cn / z.ai), Volcano Ark, MiniMax, DeepSeek, Moonshot, Kimi | `thinking: {"type": "disabled"}` |
| OpenRouter | `reasoning: {"enabled": false}` |

Set `thinking_level` to `"low"` / `"medium"` / `"high"` (the Settings page "Thinking level" dropdown) to turn thinking on in each provider's dialect:

| Provider | Attached when a level is on |
|---|---|
| Tongyi, SiliconFlow | `enable_thinking: true` (on/off only, no tiers) |
| Zhipu, Volcano Ark, MiniMax, DeepSeek, Moonshot, Kimi | `thinking: {"type": "enabled"}` (on/off only, no tiers) |
| OpenRouter | `reasoning: {"effort": "low"/"medium"/"high"}` |
| Everyone else (OpenAI official included) | `reasoning_effort: "low"/"medium"/"high"` |
| Anthropic protocol | `thinking: {"type": "enabled", "budget_tokens": 1024/4096/16384}`; `max_tokens` is raised automatically (it must exceed the budget) and `temperature` is omitted (incompatible with thinking) |

Everything else is unchanged: relay endpoints missing from the table get stray `<think>` residue stripped on the way out (the Anthropic protocol takes the first text block); a few forced-thinking models (e.g. Zhipu GLM-5.3) reject the disable parameter — choose a preset-recommended model to avoid them; a model that rejects the chosen level surfaces the provider's error.

Override the key via environment variable:

```bash
export ALTGO_POLISHER_API_KEY="sk-your-key"
```

## Key Binding Configuration

Consistent with [`configs/altgo.toml`](https://github.com/cislunarspace/altgo/blob/master/configs/altgo.toml); the default trigger key is **right Alt**. If you use "Press to set" on the Settings page, Linux writes the `linux_evdev_code` field.

```toml
[key_listener]
key_name = "Alt_R"                 # trigger key (example: right Alt; left Alt via Alt_L)
long_press_threshold_ms = 200      # long-press threshold (ms)
double_click_interval_ms = 300     # double-click window (ms)
min_press_duration_ms = 100        # minimum press duration, filtering IME jitter
```

## Recording Configuration

```toml
[recorder]
sample_rate = 16000                # fixed SenseVoice sample rate; other values are rejected
channels = 1                       # mono
```

## Output Configuration

```toml
[output]
prefer_polished = true             # clipboard/injection prefer polished text when it succeeded and is non-empty
```

On **Linux**, one of **`xclip`, `xsel`, or `wl-copy`** must be available; otherwise automatic clipboard writing fails (you can still copy via the overlay window or the history page).

## Logging Configuration

```toml
[logging]
level = "info"                     # debug / info / warn / error
```

An environment variable works too:

```bash
# Linux
RUST_LOG=altgo=debug altgo
```

## Precedence

**Environment variables > config file > code defaults**

| Environment variable | Field overridden |
|---------|---------|
| `ALTGO_POLISHER_API_KEY` | `polisher.api_key` |
| `RUST_LOG` | Log level |
