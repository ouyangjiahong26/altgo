标题栏与浮动底栏

标题栏高 42px，只承担两件事：显示这是 altgo、提供拖拽与窗口按钮。页面切换放在窗口底部的浮动底栏里， 内容因此能一直顶到窗口上沿。底栏是胶囊形，距窗口下沿 14px 居中，高 44px，内含两项。

标题栏

altgo
语音转文字
品牌标记 18px + 字标 14px/600，副标题 11px 且用左侧发丝线与字标分隔。窗口按钮 28×26，关闭按钮悬停转红。

浮动底栏

主页 设置
当前页用 surface-2 实底加 text 色文字。悬停只换底色，不做位移。
主页 设置
有新版本时在设置项的图标角上挂一个 6px 红点，不改变按钮尺寸。
底栏是唯一的全局导航，不往上加其他控件。内容区用 padding-bottom: calc(--dock-height + --dock-inset + 12px) 让位，滚到底时最后一行不被压住。

悬浮窗

窗口几何由 Rust 侧固定为 280×64，胶囊恒为 248×40，三个相位共用同一条几何：相位切换只换内容、不改变外框。 窗口用实色面加一圈发丝线，不加投影（半透明阴影在部分 Linux 合成器上会预乘成黑影）。

录音：7px 红点（带脉冲外环）与中性灰电平轨迹，轨迹视口固定 158px。
转写中：琥珀环形指示加 158px 进度线。拿不到进度时改成往复滑动的不定态。
这是转写并润色后的单行结果文本，超出会被省略号截断
完成：绿色圆盘加单行结果，关闭按钮悬停胶囊时才淡入（默认透明但保留占位）。
润色失败，已使用原文
润色失败：圆盘转琥珀，文本后跟一个 ⚠，悬停可看原因。
退出相位：整胶囊下移 8px 并淡出
退出态：内层透明度归零，审查页里保留 50% 透明度以便看清位移后的位置。
动画只动 transform 与 opacity：容器负责位移，胶囊负责淡入淡出，内容按相位替换。 胶囊圆角 10px（--radius-lg），波形走中性灰，红色只留在录音点上。

更新说明窗

340×400 的不透明无边框窗。结构与主窗一致：自绘标题栏、内容区、底部操作区，三段之间用发丝线分隔。 差别是这里没有导航，窗口只服务一件事。
