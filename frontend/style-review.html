读法：每个色块都写出变量名与当前主题下的计算值，切换主题/字号会实时刷新。图标为 16px 占位 SVG（形状不代表 lucide 实现），版式、间距、色值均来自真实 CSS。

色彩 token

来源 design-tokens.css：结构 token 在 :root，配色分 [data-theme="dark"]（默认，同时挂在 :root）与 [data-theme="light"] 两套。每个色块的外框底纹是透明棋盘格，便于看清 alpha 色值。

排版

字号全走 --text-*（rem 基准），根字号三档 15 / 17 / 19px 由 ui-size.ts 的 applyFontSize 写入 html 的 inline font-size；此处切换等价。字体族 --font-sans / --font-mono， 无网络时回退到系统字体。

更新说明窗口

手动检查发现新版本时弹出的独立窗口（label update-notes，340×400，无边框、不透明，随应用启动隐藏加载、关闭走 hide）。内容取自 latest.json 的 notes（CHANGELOG.md 当前版本小节），经受限 Markdown 渲染： ### 分类、- 条目（两个空格缩进为子条目）、行内粗体与代码；条目只显示冒号之前的小标题， ## vX.Y.Z 版本行与末尾的对比样板行不渲染（版本与日期在头部展示）。
