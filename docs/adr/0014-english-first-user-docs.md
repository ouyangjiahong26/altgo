# 对外材料以英文为主，文档站中英双语

ADR-0007 决定仓库文档与 README 保持中文单语，依据是 AppImage 目录只按截图 OCR 判定界面语言，README 中文不影响收录。对外分发范围扩大后，英文读者需要可直接阅读的入口，GitHub 仓库描述、README 与用户文档应默认英文，同时保留中文版本，避免现有中文用户失去入口。

## 决策

- 根目录 `README.md` 为英文，中文内容保留在 `README.zh-CN.md`，两份顶部互相链接。
- 文档站默认语言改为英文，新增 `zh-Hans` locale。英文正文在 `docs-site/docs/`，中文译文在 `docs-site/i18n/zh-Hans/`，导航栏提供语言切换。
- 用户文档与 README 以英文为首读版本，中文译文跟随英文更新。维护者文档（`CONTRIBUTING.md`、`docs/`、`AGENTS.md`）保持中文。
- 文档站的英文页面位于 `/altgo/`，中文页面位于 `/altgo/zh-Hans/`。GitHub Pages 不支持重定向，旧 `/altgo/docs/...` 链接现在指向英文页面，仓库内引用已按语言更新。
- README 的结果相位插图保留中英两份，英文 README 使用英文示例文案，中文 README 使用中文示例。

## 后果

- ADR-0007 中“仓库文档与 README 保持中文单语”一条不再有效，界面语言自动检测与错误文案码化的决策保持不变。
- 新增或修改用户文档时需要同时更新两个语言版本，缺少中文文件时页面回退到英文。
